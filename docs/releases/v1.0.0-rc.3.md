# CORNETO 1.0.0 RC3

CORNETO 1.0.0 RC3 expands the candidate 1.0 signaling and metabolism workflows
and moves publication to a public-`main` release gate.

## Highlights

- `CellNOptDAG` provides class-based Boolean signaling-model inference,
  including dedicated model and fit visualizations.
- The FBA and iMAT guides have been overhauled, including a new standalone iMAT
  guide and refreshed multi-condition examples.
- Public releases now use one pull request directly into public `main`; that PR
  runs the Python 3.11–3.13 tests, quality checks, warning-free documentation
  build, and package smoke test before a release tag is created.

## Experimental API cleanup

The experimental `cellnoptILP` function and `corneto.methods.signal` namespace
have been removed without compatibility shims. Use the supported class-based
API instead:

```python
from corneto.methods.signaling import CellNOptDAG
```

See the [1.0 migration guide](migration-1.0.md) for the complete supported
surface and intentional removals.
