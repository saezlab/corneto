# Release v1.0.0-rc.9 {bdg-warning}`Pre-release`

CORNETO 1.0.0 RC9 fixes shortest paths on undirected and mixed graphs and adds
a reusable biological signaling plotting preset.

## Highlights

- Shortest-path costs now account for both traversal directions of undirected
  edges while preserving directed-edge restrictions and original edge indices.
- Single-path solving stays an LP, including when the solver returns a
  fractional mixture of equally optimal paths. Path extraction removes
  zero-cost circulations without an automatic integer solve.
- Multi-condition shortest paths support reverse traversal, a single condition,
  and shared-edge L0 regularization that counts opposite traversals once.
- Fixed PICOS single-path objective construction and missing-solution handling.
- Updated generated gallery cards for Sphinx Design 0.8 while retaining
  compatibility with earlier documentation environments.
- Added the `signaling_biology` plotting preset, with explicit receptor,
  regulator, and measured-node annotations, activity colors, and interaction
  arrowheads. Its theme and processor can also be reused independently.
- Expanded regression coverage across CVXPY and PICOS for weighted directed,
  undirected, and mixed graphs, endpoint orderings, ties, and shared support.

## Compatibility

`shortest_path` now defaults to `integral_path=False`. Explicit
`integral_path=True` remains available. Shortest-path methods require finite,
nonnegative edge costs and reject hyperedges. When reusing a flow graph with
`create_flow_graph=False`, explicit weights must cover that existing graph,
including its boundary edges.

`solve_shortest_path` keeps its return tuple and includes artificial source and
sink edges in the returned indices. The selected edges describe one simple
optimal path; the returned problem retains the original LP flow, which may
be fractional when paths tie. `integer_tolerance` controls which numerical
zero flows are ignored during extraction. Unreachable targets raise
`ValueError`.

The new plotting preset is opt-in. Existing plotting defaults are preserved.
