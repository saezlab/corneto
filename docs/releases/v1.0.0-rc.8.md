# Release v1.0.0-rc.8 {bdg-warning}`Pre-release`

CORNETO 1.0.0 RC8 improves binary total-variation modeling and fixes iMAT
threshold and structured-regularization behavior.

## Highlights

- Added exact total variation for binary selections, including support for
  maximizing switch counts and handling zero-weight pairs.
- Fixed iMAT threshold rewards so flux below the activity threshold remains
  feasible without receiving the high-expression reward.
- Avoided unnecessary flux indicators when structured regularization is off,
  and corrected reaction-union regularization for single-condition models.

## Compatibility

The total-variation API adds an optional `exact` argument. Its default keeps
the existing continuous absolute-value formulation. iMAT now treats its
activity threshold as a reward condition rather than a feasibility restriction.
