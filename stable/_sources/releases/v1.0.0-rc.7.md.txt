# Release v1.0.0-rc.7 {bdg-warning}`Pre-release`

CORNETO 1.0.0 RC7 adds structural causal model simulation and expands network
file interoperability, while improving graph and documentation workflows.

## Highlights

- Added a reusable structural causal model simulation API with configurable
  mechanisms and noise, plus guides for simulation and simulated linear DAGs.
- Expanded network file reading, including SBML and SIF, and refined metabolism
  and signaling workflows.
- Added graph total variation support and shared stable topological sorting.
- Improved documentation builds with cached, solver-aware notebook execution
  and expanded causal and signaling examples.
- Updated AnnNet examples and compatibility handling for its current node API.

## Compatibility

This release candidate adds public structural causal-model simulation and I/O
APIs. The AnnNet integration targets its current node API.
